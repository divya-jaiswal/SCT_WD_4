# ✅ To-Do Web App (Internship Task 04)

This is a basic **To-Do Web Application** created using **HTML, CSS, and JavaScript** as part of **SkillCraft Technology Internship - Task 04**.

---

## 📌 Features
✅ Add new tasks  
✅ Set Date & Time for tasks  
✅ Display tasks in a list  
✅ Mark tasks as Completed  
✅ Edit tasks  
✅ Delete tasks  

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run the Project
1. Download or Clone this repository  
2. Open the folder in **VS Code**
