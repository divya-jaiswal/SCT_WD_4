# ✅ To-Do Web App (Internship Task 04)

This is a basic **To-Do Web Application** created using **HTML, CSS, and JavaScript** as part of **SkillCraft Technology Internship - Task 04**.

---

## 📌 Features
✅ Add new tasks  
✅ Set Date & Time for tasks  
✅ Display tasks in a list  
✅ Mark tasks as Completed  
✅ Edit tasks  
✅ Delete tasks  

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

---

## 📂 Project Structure
ToDo-Web-App/
│── index.html
│── style.css
│── script.js
│── README.md

---

## ⚙️ How It Works
1. User enters a task in the input box.
2. User selects the task Date & Time.
3. On clicking **Add Task**, the task gets added to the list.
4. Each task has buttons to:
   - ✅ Mark as Done
   - ✏️ Edit Task
   - 🗑️ Delete Task

---

## 🚀 How to Run the Project
1. Download or Clone this repository  
2. Open the folder in **VS Code**  
3. Run `index.html` in any browser  
   ✅ Recommended: Use **Live Server Extension**
